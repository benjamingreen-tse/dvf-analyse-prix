# DVF price analysis (Haute-Garonne)

Personal R project: import, clean, describe and visualise real-estate transaction prices, to practise a reproducible data-analysis workflow (R, tidyverse, Git, later Quarto).

## Data
Source: DVF géolocalisées (Etalab), derived from the DGFiP "Demandes de valeurs foncières", published on [data.gouv.fr](https://www.data.gouv.fr/fr/datasets/demandes-de-valeurs-foncieres-geolocalisees).

Input: national file for 2025 (`full-2025.csv.gz`), filtered to Haute-Garonne (département 31) by `R/02_filter_31.R`.

The raw file is **not** in this repository. Download it manually and place it in `data/raw/` before running the scripts. Both `data/raw/` and `data/clean/` are ignored by Git: `data/clean/` is regenerated by the scripts.

## Structure
- `data/raw/`: original files, never modified, not tracked by Git
- `data/clean/`: files produced by the scripts, not tracked by Git
- `R/`: scripts, run in numerical order
  - `00_setup.R`: packages, paths and column types shared by all scripts (reads no data)
  - `01_import.R`: reads the national file and runs data quality checks (removes nothing)
  - `02_filter_31.R`: keeps Haute-Garonne and writes `data/clean/dvf_31_2025.csv`
  - `03_clean.R`: keeps ordinary sales of exactly one house or flat, computes price per m2, writes `data/clean/dvf_31_2025_logements.csv` and the exclusion table
  - `04_describe.R`: median price per m2 by dwelling type, commune, month and zone (Toulouse vs rest); writes the tables and figures in `output/`
  - `05_robustness.R`: sensitivity of the medians to the four cleaning bounds, which side the price/m2 bounds remove, and the December check (sales per month at each stage of the funnel)
- `output/`: figures (`output/figures/`) and tables (`output/tables/`); `exclusions_03_clean.csv` gives the number of sales left after each cleaning step
- `report/`: Quarto report (`dvf_report.qmd`), rendered to a self-contained HTML

## Main results (2025, Haute-Garonne)
- 19,230 sales kept out of 28,016 recorded (ordinary sales of exactly one house or flat, plausible price and surface).
- Median price per m2: 2,951 EUR for flats, 2,695 EUR for houses.
- The flat/house gap reflects location: most flats are sold in Toulouse, most houses are not. Within Toulouse houses are more expensive; outside Toulouse the two types are almost the same.
- Monthly median prices are flat over the year; volumes vary (peak in July, high in December).
- Medians move by less than 1% when any cleaning threshold changes (`R/05_robustness.R`).

Full write-up with figures, caveats and limits: `report/dvf_report.qmd` (rendered to `report/dvf_report.html`; download the file and open it in a browser).

## Reproduce
1. Install R, the packages `tidyverse`, `here`, `knitr`, `rmarkdown`, and [Quarto](https://quarto.org).
2. Download `full-2025.csv.gz` from the data.gouv.fr page above and put it in `data/raw/`.
3. From the project root, run in order: `R/02_filter_31.R`, `R/03_clean.R`, `R/04_describe.R`, `R/05_robustness.R` (e.g. `Rscript R/02_filter_31.R`). `R/01_import.R` is an optional diagnostic and can be skipped.
4. `quarto render report/dvf_report.qmd`.
